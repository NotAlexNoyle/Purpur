# Patches

Paperweight patch files. This is the actual edit target for Purpur development.

## Layout
- `api/` — patches applied on top of Paper-API to produce Purpur-API
- `server/` — patches applied on top of Paper-Server to produce Purpur-Server

## Conventions
- Numbered `NNNN-Title.patch`, sequential, no gaps
- Generated by `./gradlew rebuildPatches` after edits in the generated trees
- Never edit `Purpur-API/` or `Purpur-Server/` directly and commit those — always rebuild patches

See context/kits/ for requirements that drive new patches.
See context/plans/ for task dependency graphs.
